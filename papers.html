沿用你的 Kimi 账户。API 密钥只放在分析服务中；这里填写服务网址和个人访问码。

访问码仅保留在当前标签页会话；备份不包含连接设置。

配置或更新个人分析服务
  1. 打开 Cloudflare 控制台，在 Workers & Pages 创建 Worker，可先选择 Hello World。
  2. 部署后打开 Edit code，用下面按钮复制的完整代码替换默认代码，再部署。 下载代码
  3. 在 Worker 的 Settings → Variables and Secrets 添加两个 Secret：MOONSHOT_API_KEY 填你的 Kimi API 密钥；ACCESS_TOKEN 填下方生成的个人访问码。
  4. 保存并部署。默认使用中国区 Kimi API 与 kimi-k2.6。如需其他模型，在同一位置添加变量 KIMI_MODEL；国际区密钥可将 MOONSHOT_BASE_URL 设为 https://api.moonshot.ai/v1。
  5. 将该 Worker 的 HTTPS 网址和相同访问码填入上方，保存并测试连接。以后上传论文无需重新配置服务。

网站不能自动读取 Autumn 在你电脑中保存的密钥。不要把密钥粘贴到代码或 GitHub 仓库。
