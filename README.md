# 脑区探索室 · Brain Atlas Lab

一个可在线访问、也可打包后离线运行的交互式脑区学习网站。

## 在线访问

https://tonyautumn.github.io/brain-atlas/

提交到 `main` 分支后，GitHub Actions 会自动把最新版发布到同一个网址。

## 主题与文献（papers.html）

上传一篇论文或粘贴正文，连接个人 Kimi 分析服务后生成可编辑的机制草稿。可补充关键图表截图。主题支持多文献汇总、单篇多主题、主题重命名/合并；每条机制保留原文证据及其来自哪篇论文。点击主题或机制可在三维图中查看对应区域与关系示意。

页面已提供分析服务的完整代码、配置说明和连接测试。**首次需部署服务并配置现有 Kimi API 密钥；GitHub Pages 本身不运行 Kimi 后端。**密钥保存在服务端，个人访问码仅保存在当前标签页会话。详见 [services/README.md](services/README.md)。

文献、原始文件、提取文本与编辑后的分析保存在浏览器 IndexedDB，不公开上传到 GitHub。JSON 备份包含主题、证据、提取文本和定位，不包含原始 PDF 与连接密钥。支持导入合并，已有相同编号的文献不被覆盖。原有解剖学习标记继续使用原键。

匹配记录与当前三维可见性独立保存。编辑菜单保留原目标（包括另一侧半球或当前暂不能显示的条目）；备份保留这些记录及最近 12 次匹配修改。“恢复 / 补充缺失匹配”优先使用已有历史，再使用已保存的检索术语和本地规则，不覆盖现有目标。恢复仅能利用仍在浏览器或备份中的信息，不能找回已彻底清除的个体记录。

本机保存按顺序执行并显示完成状态；失败时提供重试与导出，其他标签页通过版本检查避免覆盖。“结构记录与功能网络”参考模式保留全部历史结构，包括尚未关联证据的记录。默认主图仅展示通过筛选的定位证据；“显示全部合格证据”清除证据范围筛选。三维切换先准备再替换，加载失败保留前一幅图并提示重试；同一范围更新保持视角。联网重试不因缺少结果而清空已有、带来源的参考点或细胞示意点。

运行 `node scripts/validate-persistence.mjs` 回归测试匹配保存、历史恢复、检索失败合并、并发保存和三维切换；部署前自动执行此测试及研究数据测试，使用临时示例数据，无 Kimi 调用。

首次主题「濒死体验」是空入口，不预填虚构论文或机制。分析默认待核对；只允许把已核对的图谱定位标记为已学习。动物脑区、侧别不明确的区域、细胞类型与单神经元不会被强行投到人脑底座中。当前连线不是真实纤维轨迹，也不等同于完整传导机制。

运行 `node scripts/build-kimi-worker.mjs` 生成独立服务脚本；`node scripts/validate-research.mjs` 检查数据和服务协议（模拟 Kimi 响应，无实际付费调用）。

## 三维解剖（首页）

首页现为真实解剖三维空间，支持旋转、平移、缩放、半球显示、外壳透明度、矢状/冠状/轴状裁切、中英文检索、点击详情、定位放大、区域着色及浏览器本地学习记录。

- Julich-Brain v3.1：400 个左右分开计数的精细分区；包含海马 CA1/CA2/CA3、齿状回、下托复合体，岛叶亚区、丘脑核团、杏仁核核群及小脑深部核团。
- CIT168：32 个左右分开的皮层下条目，单独切换显示。
- AAL：26 个小脑分叶条目。
- ICBM152 2009：真实解剖参考表面。458 是可选图谱条目数，包含不同图谱的重叠结构，并非人脑的唯一脑区总数。

三维模块位于 `anatomy/`，全部显示资产随站点分发。首次加载约 11 MB；不依赖外部 CDN。通过 HTTPS 网址打开，需要支持 WebGL 与 DecompressionStream 的现代浏览器。三维模块不包含在旧的单文件离线版中。

选择大结构时以固定颜色突出整组（如皮层紫色、海马金色、丘脑绿色），具体亚区使用亮蓝色。「隐藏其他结构」或「只看当前选择」会保留当前整组／单个亚区并隐藏参考外壳；再次关闭即可恢复背景。

导航分为「大结构 → 脑叶或核团分组 → 图谱条目」，详情路径可点击返回上级。大脑皮层下提供额叶、顶叶、颞叶、枕叶、岛叶、扣带皮层和交界及跨叶区域；其他入口分别组织海马与杏仁核、深部核团、脑干、小脑。图谱通过独立下拉框切换，未收录入口置灰。分组高亮只覆盖当前图谱收录的分区，不等于完整脑叶体积。

导航映射位于 `anatomy/navigation.js`，独立于原始标签、几何和学习记录 ID。运行 `node scripts/validate-navigation.mjs` 核对归属、关键解剖位置、整组选择和单区隔离。

数据来源、许可、坐标和转换方法见 [anatomy/SOURCES.md](anatomy/SOURCES.md)。运行 `node scripts/validate-anatomy.mjs` 验证资产、网格与标签。`scripts/build-anatomy.py` 可从已下载的源图谱重新生成网格（需 NumPy/SciPy）。

基础内容现在位于 `basics.html`，旧的专题、卡片、测验及笔记均保留；原有浏览器记录使用原键，不迁移或清空。后续论文证据应通过稳定的图谱 ID 关联，不把示意节点冒充单神经元。

## 包含内容

- 13 个主要脑区与两种示意视角
- 核心功能、典型实验、结果解读、记忆技巧和常见误区
- 搜索、系统筛选、记忆卡与随机测验
- 进阶专题系统：通路图、实验、关键文献、前沿争议和独立测验
- 学习进度与个人笔记本机保存
- 键盘操作和移动端适配

## 离线运行

双击 `Brain-Atlas-Offline.html` 即可。所有样式、数据和交互均已打包在单一文件中。文件名使用英文是为了避免 Windows 批处理和压缩软件的中文编码问题。

基础版也可以打开 `basics.html`。三维首页请通过在线网址访问。

## 扩展新脑区

主要内容集中在 `data/regions.js`。复制一个脑区对象并修改以下字段：

- `id`、`name`、`latin`：唯一标识和中英文名
- `system`：`cortex`、`deep` 或 `support`
- `view`：默认定位到 `lateral` 或 `deep`
- `summary`、`functions`：简介与核心功能
- `experiment`：实验名称、研究问题、基本做法与结果指标
- `memory`、`pitfall`：记忆技巧与常见误区
- `quiz`：测验题、选项、正确答案与解释

进阶专题集中在 `data/deep-dives.js`。每个专题包含 `pathway`、`models`、`experiments`、`papers`、`frontiers` 和 `quiz`，后续可以按相同结构逐个加入新的脑区或神经回路。

如需在脑图中显示新区域，再在 `basics.html` 的 SVG 中加入带有 `data-region="你的-id"` 的图形即可。界面会自动读取颜色、选中状态和无障碍标签。

## 定位证据优先（atlas-evidence-v1）

`research/evidence-policy.js` 从原始记录生成显示结果，不删除论文、匹配、学习状态或原文。默认列表检查：明确的实验方法与原文位置、可核验摘录、摘录实际支持的纯人类脑结构、已存在的图谱对应或有来源的图谱参考点。仅给结构挂上标签不能通过。单区结果是定位证据，脑区间关系必须另附支持两端关系的原文摘录才连线；不把不同研究拼成路线。

假说、无关背景、未核验引用、缺定位与重复记录收进可展开的原因列表。功能网络参考和细胞示意保留在独立参考模式，不作为实测个体坐标。联网补全只处理有原文依据、仍缺图谱对应的结构。原文匹配包含 PDF 引用编号、软连字符和已有省略号摘录的兼容，不等于实验结论已经人工审定。

新 Worker 默认提取 1–3 条、最多 6 条简洁定位证据，强制保留行为/实验、结果、样本、侧别与来源；无合格证据允许空结果。已有论文在网页打开时自动使用新显示规则，不需要重新上传或付费重析。Worker 配置见 services/README.md。

回归测试：`node scripts/validate-evidence-policy.mjs`。覆盖背景排除、错误脑区标签、引用和数值完整性、有依据的定位补全、无来源关系禁画、原始记录与备份保留、精简 Kimi 协议。示例数据与供应商响应均为测试构造。
