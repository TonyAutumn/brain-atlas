# 结构笔记与双向层级 · 2026-09-17

结构详情新增“我的笔记”，支持新建多篇笔记和点击标题打开。顶栏“笔记”进入统一笔记库。纯层级结构与真实图谱条目都可记录；层级笔记使用 group:<id>，具体左右侧/来源条目使用 parcel:<id>，彼此不混合。图谱条目详情另有上级结构笔记入口。

笔记支持标题、纯文字正文、图片上传、粘贴截图和拖放图片；图片可添加说明、调整顺序和打开大图。正文和图片均自动保存，保存按钮和 Ctrl/Cmd+S 可立即保存。每张图片不超过 10 MB，每篇最多 20 张、总计 50 MB，上传支持 PNG/JPEG/GIF/WebP。拒绝 SVG、HTML 和外部图片链接，不执行笔记内容。

每篇笔记有 notes.html?structure=...&note=... 链接，也可返回对应的 index.html?structure=...。链接只是定位符，不包含正文或图片，只有保存或导入过数据的浏览器可打开笔记；不是云端公开分享。

右侧“直接上级”和完整层级列表中的祖先名称均变为可点击按钮，复用现有选择逻辑；不改动模型几何。全库检索、上下级浏览和笔记入口也可在 WebGL 不可用时使用。

## 数据安全

独立 IndexedDB：brain-atlas-structure-notes-v1。原学习记录、文献 IndexedDB、备份格式和模型 ID 不迁移或清除。数据库事务完成后才显示“已保存”；保存采用版本检查，其他标签页修改或删除时不会被旧版本覆盖。失败保留编辑器改动，可重试、另存副本或导出未保存草稿。切换笔记前先保存，未保存关闭页面时发出提醒。

“导出全部笔记（含图片）”或“导出当前结构”生成包含图片数据的 JSON。导入先校验完整备份，再事务性写入；同编号条目另存副本，不覆盖当前笔记。笔记不调用 Kimi、不上传 GitHub、不同步到其他设备。清除网站数据、隐私模式结束或浏览器回收存储都可能删除本地笔记，重要内容须定期导出。此备份独立于文献库 JSON 备份。

## 模块和验证

model.js：编号、限制与图片备份格式；store.js：事务和冲突检查；app.js：独立笔记编辑页；atlas-integration.js：通过公开 brainAtlas API 与右侧详情 DOM 的直接子节点更新挂接，不修改主渲染器。现有页的渲染不会改变笔记关联键。

node scripts/validate-notes.mjs
python scripts/validate-notes-browser.py
